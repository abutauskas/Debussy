# Security policy

Please **don't open a public issue** for security problems.

Report them privately through GitHub: the repository's **Security** tab → **Report a vulnerability**. Include what you
found, how to reproduce it, and what it affects (the Python package, the API server, the debussylabs.com sign-in,
API keys or gateway).

We'll acknowledge reports as soon as we can and tell you when a fix is out. Supported version: the latest release.
