Debussy Labs builds fast, honest decision models for AI agents.

Our first model, Debussy, is an open System 1 decision model. It makes the quick calls an agent needs (is this request safe, should I call this tool, do I actually know this) in a single pass on an ordinary CPU, and it says “I don't know” when it doesn't.

Models

  • debussylabs/debussy: safety judgements, tool-call routing and knowledge questions with “I don't know”. Apache-2.0.

Estimated Decision Index ≈ 63.7 on the Artificial Analysis Decision Index (our own estimate, not an official score). Built and evaluated on a 4-core CPU, with no GPU and no API key.
