Introducing Debussy

An open System 1 decision model for AI agents, built on a 4-core CPU with no GPU and no API key.

→
Debussy Labs
News GitHub Model card Licence

Debussy is released under Apache-2.0 and builds on Qwen3.5-4B and K2-Horizon-7B (both Apache-2.0) and llama.cpp. Built with help from Claude, Anthropic's AI assistant. Debussy is not an Anthropic model. Named after the composer Claude Debussy: the logo is a Clair de lune crescent and an Arabesque curl.
